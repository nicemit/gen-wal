Gen-Wal

A tiny daemon that changes your wallpaper once a day.

GitHub
curl -sL https://gen-wal.laptopserver.dev/install | bash

Runs locally by default. Optional AI providers can be enabled.

A small experiment born from curiosity. Runs once a day to generate a new desktop wallpaper. Uses minimal text and visual context. Designed to be subtle and ignorable.

Customization

Gen-Wal can generate wallpapers using:

  • • Procedural algorithms (mesh, flow, voronoi, waves)
  • • Your own generator plugins
  • • AI models (OpenAI, Ollama, LMStudio, Gemini)

Plugins

Bring your own generator.

Drop a Python file into:

~/.local/share/genwal/providers/images/

Gen-Wal will automatically discover it.

Themes

Text files that define the theme. Create your own to match your specific goals.

Stoic

"What stands in the way becomes the way."

Minimal

"Clarity over complexity."

Terminal

"Ship it. Iterate. Ship again."

Create Your Own

Define your own source.
Simply edit a text file.

Themes inject their settings into config.json when applied — no runtime parsing.
